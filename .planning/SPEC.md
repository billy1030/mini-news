# Technical Architecture and Spec: Mini-News

## Data Source
- URL: https://mutemute.com/mutenews/ajax/app-news.php
- Method: POST
- Polling Interval: 60 seconds (configurable via `POLL_INTERVAL_SECONDS`)
- Cursor / Deduplication: Keyed by `id` with idempotent upsert (`ON CONFLICT DO NOTHING`)

## PostgreSQL Schema & pgvector
- Extension: `CREATE EXTENSION IF NOT EXISTS vector;`
- Encoding: UTF-8 (strict handling for CJK text, emoji, and currency/market symbols)
- Timezone: Internal UTC timestamps (`timestamptz`), pre-calculated HKT (`date_hkt`, `time_hkt` in `Asia/Hong_Kong`)

### Table: flash_news
- `id` (VARCHAR(64) PRIMARY KEY): News unique ID from source
- `created_at` (TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW()): UTC publication timestamp
- `date_hkt` (DATE NOT NULL): YYYY-MM-DD in Hong Kong Time
- `time_hkt` (VARCHAR(8) NOT NULL): HH:mm or HH:mm:ss in Hong Kong Time
- `importance` (INTEGER NOT NULL DEFAULT 0): 0: Normal, 1-2: Notable, 3: Flash / Breaking Alert
- `is_alert` (BOOLEAN NOT NULL DEFAULT FALSE): Highlighted red-banner news
- `category` (VARCHAR(64) NOT NULL DEFAULT 'general'): News classification
- `raw_content` (TEXT NOT NULL): Full flash news text
- `tickers` (JSONB NOT NULL DEFAULT '[]'::jsonb): Array of stock/crypto tickers (e.g. `["AAPL", "NVDA", "BTC"]`)
- `direction` (VARCHAR(16) DEFAULT 'FLAT'): Market sentiment/direction ('UP', 'DOWN', 'FLAT')
- `embedding` (VECTOR(1536)): Optional pgvector embedding for semantic retrieval

### Indexes
- `idx_flash_news_created_at` ON `flash_news` (`created_at` DESC)
- `idx_flash_news_date_hkt` ON `flash_news` (`date_hkt` DESC)
- `idx_flash_news_importance` ON `flash_news` (`importance`)
- `idx_flash_news_category` ON `flash_news` (`category`)
- `idx_flash_news_tickers` USING GIN (`tickers`)
- `idx_flash_news_embedding` USING HNSW (`embedding` vector_cosine_ops) (when vector populated)

## MCP Tools Contract
1. `describe_news_schema()`: Returns PostgreSQL table DDL, column types, and sample rows for LLM SQL generation.
2. `query_financial_news_sql(sql)`: Executes read-only SQL queries generated by LLM (with AST/regex validation preventing mutations).
3. `search_news_hybrid(query, limit, timeWindowHours, ticker)`: Combined semantic vector similarity + temporal filter + ticker tag matching.
4. `get_latest_alerts(limit)`: Fast retrieval of breaking alerts (`is_alert = true` or `importance >= 3`).
