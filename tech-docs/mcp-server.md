# MCP Server & Dynamic SQL Specification

Mini-News exposes Model Context Protocol (MCP) tools for LLMs to safely query financial news.

---

## Tool Catalog

### 1. `describe_news_schema`
- **Description**: Returns table schemas, column explanations, data types, and recommended SQL query patterns.
- **Input**: None.
- **Output**: Markdown formatted schema description.

### 2. `query_financial_news_sql`
- **Description**: Executes a dynamic, read-only SQL query against the `flash_news` table.
- **Input**:
  - `sql` (string, required): Safe SELECT or WITH SQL query.
- **Output**: JSON array of matched rows (max 50 rows).

### 3. `get_latest_alerts`
- **Description**: Fetches breaking news flashes with high importance (`importance >= 2` or `is_alert = true`).
- **Input**:
  - `limit` (number, optional): Maximum records to fetch (default: 10, max: 50).
- **Output**: JSON array of alert records.

### 4. `search_news_hybrid`
- **Description**: Hybrid search supporting keyword text search, financial ticker tags, and chronological ordering.
- **Input**:
  - `keyword` (string, optional): Text to search in content.
  - `ticker` (string, optional): Financial ticker filter (e.g., `AAPL`, `BTC`).
  - `limit` (number, optional): Max results (default: 15, max: 50).
- **Output**: JSON array of news records.

---

## SQL Safety & Security Guards (`src/mcp/sqlSafety.ts`)

To protect the PostgreSQL database from unintended mutations or malicious injections generated by LLMs:

1. **Read-Only Restriction**: Only queries starting with `SELECT` or `WITH` are allowed.
2. **Keyword Blocklist**: Queries containing `INSERT`, `UPDATE`, `DELETE`, `DROP`, `ALTER`, `TRUNCATE`, `CREATE`, `GRANT`, `REVOKE`, `EXECUTE`, or `PG_SLEEP` are immediately rejected.
3. **Multi-Statement Defense**: Semicolons separating multiple statements are disallowed.
4. **Enforced Limit**: Any query without a `LIMIT` clause automatically has `LIMIT 50` appended. If a user/agent specifies a limit `> 50`, it is automatically clamped to `50`.
